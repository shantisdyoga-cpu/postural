# Contrôles automatisés de préproduction Sdyoga — 9 novembre 2026

Deux contrôles complémentaires sont disponibles :

- `test-vercel-api-2026-11-09.mjs` vérifie l’API Express sur une Preview Vercel avec des requêtes GET uniquement. Avec `VERCEL_ADMIN_COOKIE`, il vérifie aussi les listes admin en lecture seule.
- `test-preproduction-db-2026-11-09.mjs` se connecte directement à une base MySQL/TiDB de préproduction et exécute uniquement des requêtes SELECT.

## API Vercel

```bash
VERCEL_BASE_URL=https://votre-preview.vercel.app \
pnpm test:vercel-api
```

Pour les listes admin, fournir uniquement un cookie temporaire de compte admin de préproduction :

```bash
VERCEL_BASE_URL=https://votre-preview.vercel.app \
VERCEL_ADMIN_COOKIE='app_session_id=COOKIE_DE_TEST' \
pnpm test:vercel-api
```

La valeur du cookie n’est jamais affichée.

## Base de préproduction

```bash
PREPROD_DATABASE_URL='mysql://...' \
PREPROD_DATABASE_CONFIRM=I_UNDERSTAND_READ_ONLY_PREPROD \
pnpm test:preprod-db
```

Le script refuse une cible qui ne contient pas `preprod`, `staging`, `test`, `sandbox` ou `dev` dans l’hôte ou le nom de base. Il vérifie la connexion, les tables, des compteurs anonymisés et la cohérence des soldes, paiements, relations et présences. Il ne réalise aucune écriture.

Les valeurs réelles des variables et les données personnelles ne doivent pas être déposées dans Drive ou dans GitHub.
