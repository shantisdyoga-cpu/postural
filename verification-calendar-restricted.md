# Vérification — calendrier limité aux créneaux Sdyoga

Les captures desktop (1280 × 720) et mobile (375 × 812) confirment que le calendrier de réservation est bien intégré dans le formulaire. Seuls les mercredis et vendredis à venir sont activables ; les autres jours apparaissent désactivés. L’aide associée indique clairement que les cours disponibles ont lieu de 19h00 à 20h00.

Le choix d’un jour disponible continue d’alimenter la demande de réservation, la confirmation visuelle et le rappel iCalendar provisoire. Aucun débordement horizontal n’est visible sur mobile.
