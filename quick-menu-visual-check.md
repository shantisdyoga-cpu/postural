# Vérification visuelle — accès rapide

Le menu flottant est visible en bas à droite de la page publique. Sur mobile, seule l’icône est affichée afin de préserver l’espace disponible ; le bouton reste suffisamment grand pour être facilement touché. Sur ordinateur, le libellé « Infos pratiques » est visible et le bouton n’empiète pas sur l’en-tête ni sur le contenu du hero.

Le menu ouvert propose trois liens clairs : « Horaires », « Tarifs » et « Adresse du studio ». Les ancres `#schedule`, `#pricing` et `#studio` ont été ajoutées aux sections correspondantes. Le menu se ferme après la sélection d’un lien et le bouton expose son état avec `aria-expanded`.
